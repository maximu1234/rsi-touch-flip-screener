# RSI Touch Flip Screener

Отдельное маленькое приложение **вне** Multichart и алго-бота. Сетка та же, что у кнопки **«Подобрать»** на странице Алготрейдинг. В таблицу идёт **лучший торгуемый набор**: максимум чистой на всём графике (Обзор) среди ячеек с зелёным Test. Чемпион всего Обзора, если у него Test красный, в бота не берётся — его видно в подсказке к колонке «В бота».

По умолчанию биржа **Bybit** (USDT linear perpetual). BingX — заглушка, подключим позже.

Движок скопирован снимком из Multichart (`lib/`, metka-153). Если логика в алго изменится — скопировать файлы снова, см. `lib/README.md`.

## Для друга — только браузер, без терминала

Подбор может идти **целиком в браузере**: свечи качаются с публичного API Bybit, сетка считается на компьютере того, кто открыл страницу. Ключи биржи не нужны.

Выкладка (один раз, с вашего компьютера):

```bash
cd ~/rsi-touch-flip-screener
git init
git add .
git commit -m "RSI Touch Flip screener"
gh repo create rsi-touch-flip-screener --public --source . --remote origin --push
```

В GitHub: **Settings → Pages → Source: GitHub Actions**. После пуша в `main` появится ссылка вида:

`https://<ваш-логин>.github.io/rsi-touch-flip-screener/`

Эту ссылку и даёте другу. Он открывает, жмёт **Старт**, ноутбук считает ночь, утром **Сохранить CSV** (или JSON). Чтобы не считать заново — **Загрузить…** и выбрать файл, который прислали. Перед переездом с ноутбуком — **Пауза**, на новом месте — **Продолжить**. Зависший подбор или старая таблица — **Сбросить**, затем снова **Старт**.

Локально у вас по-прежнему `npm start` → http://127.0.0.1:3847 (ночной прогон на диске `data/`).

## Запуск с терминалом (ваш компьютер)

Нужен Node.js 20+.

```bash
cd ~/rsi-touch-flip-screener
npm start
```

Откроется UI: [http://127.0.0.1:3847](http://127.0.0.1:3847)

При открытии страницы поднимается прошлый прогон (с сервера и копия в браузере). Кнопка **Прошлый результат** показывает его вручную.

**Поделиться результатом:** **Сохранить CSV** или **Сохранить JSON** → отправить файл другу. У друга: **Загрузить…** → выбрать тот же файл — таблица появится без ночного парсинга.

JSON сохраняет всё (настройки прогона, Train/Test, вердикты). CSV — только то, что видно в таблице; для обмена обычно достаточно.

Тот же прогон из терминала:

```bash
npm run scan -- --universe top100
npm run scan -- --symbols BTCUSDT,ETHUSDT
```

## Сколько это занимает

Полная сетка на один тикер — около **74 970** комбинаций (RSI 5–21, OS 15–35, OB 65–85, стек 1–10). История графика как в алго: до **10 страниц × 1000** свечей 5m (~35 дней). RSI по умолчанию с **1m**.

На ноутбуке после кэша свечей полная сетка — примерно **1–2 минуты на тикер**. Все линейные USDT-перпы Bybit (сейчас ~700+) × 2 воркера — это **много часов, часто ночь**. Кэш 1m может занять несколько гигабайт в `data/cache`. Для проверки сначала:

- вселенная **Топ-100**, или
- поле «Тикеры»: `BTCUSDT, ETHUSDT`

Прогон можно поставить на **Паузу**: текущий тикер не сохранится (считается заново), готовые строки остаются. На новом месте нажмите **Продолжить** — очередь берётся из сохранённой таблицы, список биржи заново не качается. Кэш свечей в IndexedDB / `data/cache` не пропадает.

Прогон можно остановить: готовые строки пишутся в `data/results.json` после каждого тикера. Следующий Старт с теми же настройками **продолжит** с незавершённых.

Кэш свечей: `data/cache/bybit/{SYMBOL}/{tf}.json` (12 часов).

## Настройки по умолчанию

Как обычно в алго: график 5m, RSI 1m, бюджет 30 USDT, размер «средний × 1.5», комиссия 0.04%, Train 70%, обе стороны, СЛ цикла выключен.

Чек-бокс **СЛ цикла** сразу пересчитывает уже найденные наборы (те же RSI/OS/OB/стек) — полный перебор сетки не нужен.

Колонки таблицы = Обзор выбранного набора: дни, чистая / лонг / шорт / валовая / убыток, сделки, Win%, PF, просадка, средняя сделка, средние бары + параметры и вердикт Test (можно / нельзя).

«Можно» = на Test чистая > 0, достаточно сделок, PF ≥ 1. Просадка **не** запрещает. Строка «можно» — это лучшая чистая Обзора среди таких наборов, не абсолютный максимум прибыли по сетке.

## CLI

```
--exchange bybit
--universe all|top100
--symbols BTCUSDT,ETHUSDT
--workers 2
--budget 30
--chart-tf 5
--rsi-tf 1
--combo-limit 0          # 0 = полная сетка; для дыма можно 50
--force
--refresh-cache
--cycle-sl
--config config.json
```

Пример конфига: `config.example.json`.
